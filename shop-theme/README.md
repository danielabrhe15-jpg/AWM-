# AWM-Shop (Shopify-Theme)

Kopie des AWM-Shopify-Themes aus `danielabrhe15-jpg/kunden-shop` (Stand `main`, Commit d791ff4):
Zendrop-Theme mit AWM-Elektrotechniek-Inhalten (niederländische Texte, AWM-Farben, Logo und Favicon).

**Wichtig:** Dieses Theme ist Shopify-Liquid-Code. Es läuft nur in einem Shopify-Shop,
nicht auf GitHub Pages. Auf GitHub Pages wird dieser Ordner nur als Dateien abgelegt,
es gibt dort keinen Warenkorb und keine Kasse.

Verwenden in Shopify:

1. Diesen Ordner als ZIP packen (Inhalt, nicht den Ordner selbst), z. B. `cd shop-theme && zip -r ../awm-shop-theme.zip .`
2. Shopify-Admin → Onlineshop → Themes → Theme hinzufügen → ZIP-Datei hochladen.

Die GitHub-Verbindung von Shopify erwartet das Theme im Stammverzeichnis eines Branches.
Dafür bleibt `kunden-shop` (`main`) zuständig.
