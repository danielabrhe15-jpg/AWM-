# AWM-

Website für **AWM Elektrotechniek** (Niederlande), gehostet mit GitHub Pages.

- `index.html` – Startseite (Niederländisch)
- `bedrijfsgegevens.html`, `privacy.html` – Pflichtseiten
- `assets/` – CSS, JavaScript, Logo und Favicon
- `shop-theme/` – AWM-Shopify-Theme (nur in Shopify lauffähig, siehe `shop-theme/README.md`)

Platzhalter in `[eckigen Klammern]` müssen vor dem Livegang ausgefüllt werden.
